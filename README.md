# BGS Solutions Website Demo

A responsive, front-end website concept for BGS Solutions, built with plain HTML, CSS and JavaScript.

## Run locally

1. Extract the project folder.
2. Open `index.html` in a modern browser.
3. No package installation or build step is required.

## Project structure

```text
BGS-Solutions-Demo/
├── assets/
│   └── images/          # Supplied company photographs
├── css/
│   └── styles.css       # Layout, responsive rules and visual styling
├── js/
│   └── main.js          # Navigation, gallery viewer and enquiry behaviour
└── index.html           # Page structure and content
```

## Interactions

- Responsive mobile navigation with close-on-selection and Escape support.
- Current section indicator in the navigation while scrolling.
- Subtle reveal transitions as content enters the viewport.
- Click or keyboard-activate gallery photographs to view them larger; close with the button, backdrop or Escape.
- Enquiry form validates required fields and prepares a WhatsApp message for the visitor to review and send.

## Important demo notes

- The enquiry form does not store information or submit to a server. It opens a prefilled WhatsApp message.
- Confirm the contact number is WhatsApp-enabled before publishing.
- Confirm the company's service descriptions, project details, credentials and permission to use supplied photographs before launch.
- Domain, hosting and business email are not included.
